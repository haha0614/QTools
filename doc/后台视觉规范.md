# 后台视觉规范（QTools-M）

> 记录从 2026-11 开始的一轮视觉统一：做了什么、依据是什么、踩过哪些坑。
> 目的只有一个：**以后改样式时不用再靠猜，也不会再出现「改了看不见」。**

## 一、三层结构

```
第 0 层 token     src/assets/styles/qtools-tokens.scss
第 1 层 组件皮肤   src/assets/styles/qtools-components.scss
第 2 层 页面布局   逐页处理（外壳 + 各列表/表单页）
```

引入顺序在 `src/assets/styles/index.scss` 末尾（必须最后，才能覆盖 Element 默认值）：

```scss
@use './qtools-tokens.scss';
@use './qtools-components.scss';
```

## 三、组件语义（第 1 层）

- **卡片**：圆角 16、**半透明玻璃**（`--qt-glass-surface` + `backdrop-filter: blur(16px) saturate(180%)`）、
  1px 白色高光边、内沿高光、极淡外阴影。**投影只用于「浮起一层」，不用来表达层级**
- **表格**：边框=发丝线；表头 12.5px/600/次要色 + 浅灰底；行高约 44；行 hover=主色 6%
- **弹窗**：圆角 12、发丝边框、单层外阴影
- **控件高度**：输入/选择/日期统一 32px

## 三·五、玻璃方案（2026-11 定案：方案 B）

登录页与后台统一到「玻璃」这一套语言。**P6.140 起数据行也改成透明**，
可读性不再靠「行铺白」，而是靠**加重背景模糊**（16px → 28px）：

| 层 | 做法 | 依据 |
|---|---|---|
| 外壳（侧栏 / 顶栏 / 页签条） | 半透明白 + 轻模糊 + 内高光 | 面积小、位置固定，背后有网格细节 |
| 页面卡（`.app-container` / `.content-inner`） | glass surface + 28px 模糊 + 14px 圆角 | 每页只有一张，是"整页一张纸"的载体 |
| 数据行 | **透明**，直接透出容器玻璃 | 网格被 28px 糊平后文字基线不晃（实测） |
| 卡片里**再套的小卡** | 保持实心白 | 玻璃叠玻璃会把数字糊掉 |
| 表格**固定列** | **必须实底** | 固定列是浮层，自身没底会把下层滚动内容透出来（实测文字重叠） |

玻璃能成立的前提是**背景得有细节**：`.app-wrapper` 铺「三团柔光 + 48px 细网格」。
若把背景改回纯色，`backdrop-filter` 只会得到一层磨砂白——这个坑前面已经踩过两次。

**模糊半径决定网格是"质感"还是"条纹"**：同一块网格，blur 18–20px 会在侧栏上糊成一条条横向亮带
（P6.124 就是这么翻车的），blur 3px 又能看出网格线；28px 才既糊平又不出带。改半径前先看它背后是什么。

**外壳的深色玻璃必须叠在深色底上**：半透明深色叠浅色页面会被洗成灰（P6.126）。
现在侧栏走的是浅色方案，暗色模式另有一组 `html.dark` 兜底规则。

相关变量：`--qt-glass-surface / -border / -inner / -shadow`、`--qt-glow-1/2/3`、`--qt-grid-line`，亮暗各一套。

## 四、图表

统一入口 `src/utils/chartTheme.js`：

```js
import { chartTheme } from '@/utils/chartTheme'
const t = chartTheme()
chart.setOption({ color: t.ramp, xAxis: { axisLabel: { color: t.sub } } })
```

- `palette`：主色 + 语义色，用于折线/柱状/仪表
- `ramp`：主色深浅梯度，用于**饼图/玫瑰图**（同维度多分类用语义色会被误读成「红=错误」）

## 五、踩过的坑（都带证据，别再犯）

### 1. 变量定义了但没人用

`--sidebar-bg` 全项目零引用，侧栏底色真实来源是 SCSS 变量 `$menuBg`（经
`variables.module.scss` 的 `:export` 注入到 `Sidebar/index.vue`）。
改了 CSS 变量 = 什么都没发生。

同理 `--el-bg-color-page` 一度也没有任何元素使用（body / #app / .app-wrapper / .app-main
都没有背景）。现在由 `.app-main` 铺出来 —— 见 `src/layout/components/AppMain.vue`。

### 2. Element 自己也在声明同名变量

表头底色：只写 `--el-table-header-bg-color` **不生效**，Element 有同优先级声明且后加载。
要直接给 `th.el-table__cell { background-color: ... }`。

### 3. 投影换发丝线时，后面的规则会把它加回来

`sidebar.scss` 里 `&.theme-dark` 曾同时 `box-shadow: 2px 0 8px` 且 `border-right: none`，
覆盖了先写的发丝线。改外壳样式时必须搜一遍同名主题块。

### 4. 删代码别按行号

用行号区间删 `onMounted` 时连带删掉了脚本末尾的 `getCode() / getCookie()` 调用，
导致登录页验证码永远「加载中」。**按锚点字符串删**，删完 `grep` 一遍。

### 5. 页面 scoped 样式会赢过全局（同权重 + 后加载）

给页面里的分区（如 `.scan-panel`、`.derive-bar`）统一材质时，只写全局选择器**不会生效**：
组件的 scoped 样式带属性选择器且后加载，权重相同但顺序在后。必须 `!important`。

实测：给 `.scan-panel` 加玻璃后截图毫无变化，补 `!important` 才生效。

### 6. 透明行 + 固定列 = 文字重叠

`.el-table` 的固定列是**浮在上层的一层**。行透明后，它自己没底色，
下层随横向滚动的内容会直接透出来 —— 用户端页「操作」列与「操作原因」列文字叠在一起。
修法：固定列（含首末列）一律给 `var(--el-bg-color)` 实底。

另外只设 `--el-table-tr-bg-color: transparent` 不够，表格自身还有一层
`--el-table-bg-color`，两个都要关掉才真的透到容器玻璃。

### 7. 布局缺口不要当渲染问题修

登录卡底部 20px 空带的真因是 `.cover` 高度 480 < 卡片 500（`align-self: stretch` 修好），
我先猜了「合成层亮带」「DPR 采样」两个错方向。**先量盒子（browser_snapshot 给 box），再改 CSS。**

## 七、新增页面时怎么做

1. 根节点用 `.app-container`：**它本身就是那张玻璃卡**（P6.142），不要再自己铺白底；
   树形页用 `.tree-sidebar-manage-wrap`，内容卡由 `.content-inner` 提供；
2. 页面内分区（工具条/查询区/表格容器）用 `--qt-glass-surface` + 28px 模糊 + 14px 圆角，
   与卡片同一材质；页面 scoped 样式覆盖时记得 `!important`；
3. 工具栏 + 表格要成一张卡时：工具栏给上圆角、表格给下圆角（参考 `media/review.vue` 的 `.rv-tools`）；
4. 表格操作列**必须**给 `width` + `fixed="right"`，否则列宽总和超容器时会被裁；
5. 图表一律走 `chartTheme()`；
6. 改完必须**在浅色下截图核对**（导航栏有主题切换），别只确认「构建通过」。

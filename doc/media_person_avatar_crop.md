# 人物头像「框选裁剪」（P5.55）·「从视频画面挑一帧」（P5.64）

## 落库形状

`media_person.avatar_ref`（VARCHAR(512)，**无 DDL 变更**），`avatar_kind` 三值 `photo` / `url` / `frame`：

```
a164:4                                  整图（P5.48 老形状，语义与字节都没变）
a164:4#crop=0.2100,0.1300,0.5600,0.5600 裁剪：x,y,w,h 四个 0..1 比例
frame:1d74d2cc5d20:562                  视频第 562 秒那一帧（P5.64 新形状）
frame:1d74d2cc5d20:120#crop=0.1000,0.1000,0.5000,0.5000
```

- `x,y` = 左上角在图片里的比例；`w,h` = 宽高占图片的比例。
- 校验：每个值 0..1；`w,h ≥ 0.02`；`x+w ≤ 1`、`y+h ≤ 1`（`MediaAvatarCrop.normalize`）。
- **为什么存比例**：裁剪框是用户在显示尺寸的图上拖的，存像素等于把缩略图分辨率焊进库；
  缩略图一重建（`build-thumbs.js` 换尺寸）像素框就偏了。
- **为什么不用新列**：旧代码解析 `<albumId>:<seq>` 失败会回落到整图（不炸），
  所以「不认识裁剪的旧版本」读新数据 = 整图，天然向后兼容。
- **frame 型为什么不复用** `<albumId>:<seq>`：同一个字符串位置上，一个是相册序号、一个是视频秒；
  混用只能靠猜（P5.61 的 500 就是这类「占位不明确」的产物）。frame 型单独解析：
  videoId 白名单 `[A-Za-z0-9_-]{1,64}`（与 `MediaFrameServiceImpl.SAFE_ID` 同一套）、
  sec 只吃 `[0-9]{1,9}`，并校验「视频存在」+「0 ≤ sec ≤ dur」（闭区间）。

## URL

`avatarUrlOf()` 拼出：

```
photo → /api/media/thumb/p/<albumId>/<pad4(seq)>?crop=<x,y,w,h>
frame → /api/media/frame/<videoId>?t=<sec>&w=480[&crop=<x,y,w,h>]
```

`MediaFileController` 的 `/thumb/p/{albumId}/{i}`、`/thumb/p/{hash}` 与 `/frame/{id}` 都接受可选 `crop`：

- 不带 → **零变化**（原文件、原缓存头）；
- 带 → `/thumb` 走 `MediaAvatarCrop.render` 现裁，落 `<thumbs>/avcrop/<sha1>.jpg`
  （键含源文件 size+mtime，缩略图重建自动失效，不需要清理任务），压缩质量 0.9；
  `/frame` 走 `MediaAvatarCrop.cropJpeg` **在内存里现裁**（不落盘：URL 已含秒 + crop，本身内容寻址，
  `immutable` 缓存语义不变）；
- 参数非法 → **400**（不静默退成整图：用户明确选了一个框，悄悄给整图更难查）。

## 前端

`PersonAvatarDialog.vue` 三个 tab；相册图与视频帧**共用同一个裁剪块**：

- 拖拽框选（松手收成正方形；点一下不拖 = 中心 60%）；
- 缩放滑块 20–100%（占短边百分比）；
- 三档：脸部（42%，中心偏上 42%）/ 中心（60%）/ 整图（不写 `#crop`）；
- 预览用 `pv` 大图（`scale=1600:-2`），后端裁 `p` 缩略图（`scale=400:-2`）——
  两者等比缩放比例一致，框的位置即后端裁的位置；帧头像的预览就是取帧接口本身（`w=480`）。
- 第三个 tab「从视频画面」：人物的视频横向条（默认第一个）→ 6 帧候选
  （`t = dur × 0.05/0.2/0.35/0.5/0.65/0.8`，整秒，`w=480`）→ 点一帧进裁剪态；
  「换一组时间点」把比例整体后移 10%。取帧 6 个 / 批、2 并发、切视频 `AbortController.abort()`。

## 实测

- 相册图：同一张图 `/thumb/p/a161/0000` = 400×534；加 `?crop=0.2917,0.2625,0.4208,0.3156` = 168×169
  （168/400 = 0.420 ≈ 参数 0.4208）。越界参数 400、无参 200。
- 取帧：`/frame/1d74d2cc5d20?t=402&w=480` = 480×270（17327B）；
  加 `&crop=0.3729,0.2741,0.2542,0.4519` 裁成该区域（探针用「左红右蓝」合成帧验证裁剪方向：
  `crop=0.5,0,0.5,1` 采样到蓝色 = 真的切了右半，不是把整图缩放）。
